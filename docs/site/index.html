skills

41 agent skills. A skill is one folder with a SKILL.md file. A ⏸ skill runs only when you call it by name.

code

SkillWhat it does
lean-codeWrite, change or review code with the smallest correct diff. Question the need, reuse what exists, prefer the standard library, add no speculative abstraction. Use on any coding task, or for "simplest" or "yagni".
locoWrite, review or debug a Loco app (loco-rs, Rails for Rust): controllers, Sea-ORM models, migrations, workers, tasks and mailers. Use for AppContext, cargo loco, or a Loco app on a NixOS host.

dev-flow

SkillWhat it does
bipr ⏸Abre ou atualiza o PR do branch atual com título e corpo bilíngues, pt-BR primeiro e o espelho em inglês, gerados a partir dos commits. Use quando pedirem /bipr ou um PR bilíngue.
easy-issues ⏸Find small open issues that are ready for an agent, and solve each one as its own tested PR. Works for members and for contributors through a fork. Use for /easy-issues.
handoffSave and resume work sessions as handoff notes in an Obsidian vault, and keep one digest note for each project there. Use for "save this session", "write a handoff", "load my last context" or "what was I working on". Not for decisions (use mip) or conventions (use AGENTS.md).
mipWrite or revise an Improvement Proposal (MIP), a numbered design document for a non-trivial feature, integration or architecture change, written before the code. Use when the user says "MIP", "improvement proposal", "propose a feature" or "write up a design for".
mip-overnight ⏸Unattended runner for MIP task lists. Works one ready task at a time, opens a Draft PR for each, and stops cleanly at a usage limit or a real blocker. Only when typed by the owner.
mip-tasks ⏸Turn an accepted MIP into an ordered task list and deliver it as small stacked PRs, one task for each branch and PR. Use for `/mip-tasks NNNN` or a restack.
pr-images ⏸Open or update a bilingual PR like bipr, with before and after images in its body. Use for each PR that changes an image, a drawing, a page or a screen, or for /bipri.
triage ⏸Turn a raw idea, a voice note or a bug report into one issue body that is ready to claim. A human files it. Use for "triage this" or "make an issue out of this".
voice-noteTranscribe a local voice note (a WhatsApp .ogg or similar) with local Whisper, write the transcript next to the audio, then anonymize it by hand. Use when a MIP, an issue or a task needs the words of a voice note.

figures

SkillWhat it does
archifyCreate polished, validated architecture, workflow, sequence, data-flow, and lifecycle/state diagrams as explorable standalone HTML with inline SVG, dark/light themes, optional trace motion, and PNG/JPEG/WebP/SVG/WebM export. Accept plain-language requirements or pasted Mermaid flowchart, sequenceDiagram, and stateDiagram input; inspect repository evidence when the diagram must reflect real code. Use when the user asks to visualize system architecture, infrastructure, cloud/security/network topology, technical workflows, API call sequences, request lifecycles, data pipelines, ETL/ELT, data lineage, state machines, or to convert/beautify Mermaid.
ddrawDraw a one-line drawing or a brushed kanji as Desmos equations and as an SVG from the same equations. Examine the render and draw again until it is good. Use for a README drawing, a logo or art in Desmos.
figureAdd, change or explain a diagram in this repo's Markdown (README.md, README.en.md, docs): a Mermaid fence or an Archify picture. Use when asked for a diagram, flowchart, mind map or 'a picture of' something, or to update one after its prose changed.
svg-diagramDraw an architecture or repository map as one hand-written SVG for a README: a dark grid card, one colour for each kind of part, a legend. Use when Mermaid is too plain. For a figure with a reading card, use figure.

nix

SkillWhat it does
nix-debugFind why a Nix evaluation, build, activation, service or boot fails. Update inputs, pins, hashes and carried patches safely. Use for a failed nix flake check, build or deploy, a flake.lock bump, or a rescue from a live USB.
nix-labWrite or change a self-contained Nix flake lab: a toolchain or dev shell that other repositories use. Covers locks, Rust tools, a just 1.21 justfile and the local gate. Use for flake.nix, devShells or a new lab.
nixos-vpsChange the NixOS configuration of a small live VPS that a merge to main deploys (deploy-rs with magic rollback). Use for modules, services, nginx, ACME, users, the resource budget, flake updates and the deploy itself. Never deploys.
systemd-hardeningHarden a systemd service written in Nix (systemd.services.<name>) with sandboxing, capability limits and syscall filters, then prove it still works. Use when you write or review a NixOS service module.

notes

SkillWhat it does
pirsigDrive Pirsig (psg), the PARA and Zettelkasten second brain, and its Hippo rhizomes. Capture and link notes, file projects and tasks, ingest arXiv or RSS, sync Obsidian. Use for Pirsig, psg, Hippo or a fixation.
pirsig-slipsWork with ideas on paper slips, as Pirsig did in Lila: one idea on each slip, sorted by hand. Use for slips to copy, photos of slips, "which comes first" or piles to name.
zk-methodCheck that notes follow the Zettelkasten method: kind, atomicity, own words, links with reasons, sources. Lint a Markdown vault and propose fixes. Use for "is this a good zettel" or "audit my notes".

ouroboric

SkillWhat it does
retro ⏸Do a retrospective of a coding session and propose changes to the agent's environment: checks, navigation, steering files and tool cost. Use for /retro.
sharinganRead, evaluate and adopt (REA) tools from another repository, with the licence of each item decided before a copy. Use for "port this", "copy this skill" or "sharingan <url>", and before you copy any file from another repository.
writing-stylesSelect the writing style of a document from its reader: agent-facing, procedure, spec, guide, reference, research, journal, public help or UI copy. Then apply the skill and rules of that style. Use before you write a new document.

research

SkillWhat it does
citation-scoreScore how much of a text is cited, from 0% to 100%, with a coloured verdict. Use to score the citations of a phrase, a text, a file or a URL.
cite-releasePrepare a citable release and keep its Zenodo and citation metadata correct. Use to release or tag a version, mint a DOI, add an author, or change .zenodo.json, CITATION.cff or the citation block.
eli5Explain a topic of the current project to a reader who knows nothing about it. Draw a picture first and take each fact from the checkout. Use for /eli5 <topic> or "explain this simply".
open-textGet the full text of a work that is free to copy, keep it byte for byte with its licence, and index it. Use to fetch a book, story, essay or poem. When the text is not free, it gives a citation only.
paperWrite, check and prepare a citable research text (paper, proposal or report). Each claim has a mark, and a log says how each source was checked. Use for a draft, a new section or reference, or a check before a PR.

web

SkillWhat it does
citizen-scienceKeep a public open-data site checkable and easy to join - sources, freshness, method, limits, privacy, licence and how to contribute visible on each page. Use when you add or review a page, a section or a panel that shows data to the public.
mapsShow areas, points and data fields on a web map with MapLibre and free tiles first, or Mapbox GL when a project already uses it. Covers CAP alert areas to GeoJSON, data-driven styling, performance and token safety. Use for any map on a page, an app or an image.
web-uiChange or review what a visitor sees on a site. Look first, plan with the design tokens, build, then test with worst-case data and screenshots. Use for each visible change, or when a page looks plain or generated.

writing

SkillWhat it does
cientificoEscreve e revisa texto científico ou técnico com fontes (artigo, proposta, relatório) em pt-BR, e em EN quando o texto é bilíngue. Use ao redigir, citar, checar números, preparar ou responder revisão.
easy-translateMake an easy version or a controlled translation of a source document: easy pt-BR, Easy Japanese or controlled Simplified Chinese. Use for a versão fácil, a translated README or site string, or a stale translation.
essayCheck that an essay keeps the form that Montaigne gave the essay. The writer is in it, it opens on a case, it doubts and it does not teach. Use to check an essay, or to tell an essay from an article.
ptbrReescreve texto técnico em português brasileiro por nível de rigor (estrito, descritivo, leve, científico, smart-note). Use ao escrever, reescrever ou revisar runbook, documentação, comunicado ou notas em pt-BR.
ptbr-routingEscolhe a skill e o nível de rigor antes de carregar uma skill de escrita em pt-BR. Use quando o pedido é escrever, reescrever ou revisar texto em português e não diz o nível nem a skill.
ptbr-writerReescreve texto técnico em português brasileiro por nível de rigor (estrito, descritivo, leve, científico, smart-note). Use ao escrever, reescrever ou revisar runbook, documentação, comunicado ou notas em pt-BR.
retorica(em desenvolvimento) Retórica para texto técnico em português. Sem regras ainda: não use para reescrever texto.
ste100Write or rewrite English text in ASD-STE100 Simplified Technical English. Use for docs, READMEs, PR bodies, tool descriptions, error messages, prompts and agent instructions, or when a text is dense, hedged or easy to misread. Not for pt-BR text (use ptbr-writer) or for creative copy.
