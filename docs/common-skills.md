# common-skills

The skills of other authors that the projects of h0ffmann use. No file of these skills is in
this repository, except `ponytail-review` (copied as is from havamal). Each row gives the source,
the licence and the install command. A dash means that the source has no plugin: copy its folder.

| Skill | Repository | Licence | What it does | Install |
|---|---|---|---|---|
| `ponytail` | [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) | MIT | The simplest change that works, with review and audit skills | `/plugin install ponytail --marketplace DietrichGebert/ponytail` |
| `frontend-design` | [anthropics/skills](https://github.com/anthropics/skills) | Apache-2.0 | A clear visual direction for a new or changed UI | `/plugin install frontend-design@claude-plugins-official` |
| `webapp-testing` | [anthropics/skills](https://github.com/anthropics/skills) | Apache-2.0 | Tests a local web app with Playwright | `/plugin install example-skills --marketplace anthropics/skills` |
| `design-taste-frontend` | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) | MIT | Landing pages and redesigns that do not look like a template | `/plugin install taste-skill --marketplace Leonxlnx/taste-skill` |
| `karpathy-guidelines` | [forrestchang/andrej-karpathy-skills](https://github.com/forrestchang/andrej-karpathy-skills) | MIT | Rules against frequent LLM coding errors | `/plugin install andrej-karpathy-skills --marketplace forrestchang/andrej-karpathy-skills` |
| `emil-design-eng` | [emilkowalski/skill](https://github.com/emilkowalski/skill) | MIT | UI polish, component design and animation choices | - |
| `review-animations` | [emilkowalski/skill](https://github.com/emilkowalski/skill) | MIT | Reviews animation and motion code | - |
| `break-ui` | [emilkowalski/skill](https://github.com/emilkowalski/skill) | MIT | Tries to break a UI with worst-case data | - |
| `mapbox` | [mapbox/mapbox-agent-skills](https://github.com/mapbox/mapbox-agent-skills) | MIT | Seven Mapbox skills: cartography, styles, data, tokens, speed | `/plugin install mapbox@claude-plugins-official` |
| `humanizer` | [blader/humanizer](https://github.com/blader/humanizer) | MIT | Removes the signs of AI writing from English text | `/plugin install humanizer --marketplace blader/humanizer` |
| `humanizar` | [fabricioctelles/skills](https://github.com/fabricioctelles/skills) | Apache-2.0 | Removes the signs of AI writing from pt-BR text | - |
| `humanizer-pt-br` | [mackswendhell/humanizer-pt-br](https://github.com/mackswendhell/humanizer-pt-br) | MIT | A different pt-BR humanizer | - |
